Ransomware Digital Forensics Investigation

IT 221 — Ransomware Forensics
Completed

A team project simulating a real investigation into a ransomware incident on a company file server: analyzing a disk image and a memory dump using Autopsy and Volatility Framework to reconstruct the full attack sequence.

Objective

Determine how the ransomware entered the system, which file triggered the encryption, and whether there was any connection to an external attacker.

Tools
  • Autopsy (Sleuth Kit)
  • Volatility Framework
  • DFIR / Chain of Custody
Outcome

We traced the full attack sequence and extracted encryption keys from live memory — impossible with disk analysis alone — and recommended a hybrid approach (always capture memory before disk imaging).
